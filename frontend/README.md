# Frontend

Thư mục này chứa code giao diện người dùng (Web UI) cho hệ thống Smart Learning Support.

## Công nghệ dự kiến
- Framework: React / Vue / hoặc framework khác
- Giao tiếp với backend qua REST API hoặc WebSocket
